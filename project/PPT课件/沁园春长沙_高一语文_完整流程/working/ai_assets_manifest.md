## 二、AI-01：AI 视频（湘江秋景动态意境）

### 2.1 基本字段

| 字段 | 内容 |
|---|---|
| ai_id | AI-01 |
| ai_type | AI 视频 |
| teaching_role | 情境还原：把「万类霜天竞自由」的湘江秋景由文字转为动态画面，支撑色彩、空间、动静、意境四维解说 |
| linked_objective | 教学目标 3（品读写景艺术、赏析意境）；教学重点（赏析湘江秋景壮阔蓬勃的意境特点） |
| teacher_action | 教师在学生完成四维分层解说后出示画面；按「色彩—空间—动静—意境」顺序逐层追问，要求学生用画面印证自己的解说词 |
| student_action | 学生对照画面，检查并打磨本组导游解说词，指出画面中与词句对应的意象 |
| duration | 课前生成；课堂展示与追问约 3 分钟 |
| required | true |
| status | planned |
| execution_owner | Agent B |

### 2.2 生成输入

- 资源路径：`resources/ai_video/`（待 Agent B 生成）
- 建议文件名：`ai-video-01-xiangjiang-qiujing-1080p.mp4`
- 建议规格：1920×1080、16:9、时长 8—12 秒、无声轨或低音量环境音
- 画面必须包含的六个意象：万山、层林、漫江、百舸、鹰、鱼
- 风格取向：秋日湘江橘子洲，层林尽染、江水澄碧、百舸争流、鹰击长空、鱼翔浅底；壮阔蓬勃、昂扬雄浑，**不得出现萧瑟凋零、暮色残秋的意象**

提示词要点（供 Agent B 参考）：

> 秋日湘江橘子洲全景，远景岳麓山万山红遍、层林尽染，中景湘江碧透、百舸争流，仰视雄鹰击于长空，俯视游鱼翔于浅底；光线明亮通透，色彩以赤红与澄碧为主，生机蓬勃、气象壮阔；写实国风，不使用人物特写，不添加词作以外的元素。

### 2.3 预期产出

一段 8—12 秒的动态意境画面，能在单屏内呈现远近俯仰的空间层次与红绿相生的色彩关系，供学生印证「万类霜天竞自由」的四维解说。

### 2.4 核验（verification）

1. 画面须能数出词中六个意象：山、林、江、舸、鹰、鱼，缺一即重生成。
2. 画面基调须为「壮秋」而非「悲秋」：不得出现枯枝败叶、暮霭沉沉、孤舟独钓等悲秋符号。
3. 不得出现现代建筑、现代桥梁、霓虹灯光等与 1925 年语境冲突的元素。
4. 教师放映前须自行预看一次；与文本不符时不使用。

### 2.5 备用方案（fallback）

| 故障情形 | 替代方案 |
|---|---|
| 平板或网络不可用 | 教师端单机演示同一段视频，学生改为观看后口头解说 |
| 视频无法播放 | 改用静态 AI 生成的湘江秋景全景图一张，四维解说改由教师板画示意图辅助 |
| 完全无多媒体条件 | 学生闭目想象 + 教师语言描述，直接进行四维解说与展演，教学闭环不受影响 |

### 2.6 权利与交接

- rights_note：AI 生成内容，非实景照片、非历史影像；课件中须标注为「AI 生成示意画面」，不得标注为橘子洲实景或历史资料。
- handoff_note：Agent B 按 `resources/ai_video/` 生成并嵌入课件；finalize 后若重跑须再执行媒体回填脚本。

## 三、AI-02：HTML 互动（意象空间归类）【补充】

### 3.1 基本字段

| 字段 | 内容 |
|---|---|
| ai_id | AI-02 |
| ai_type | HTML 互动 |
| teaching_role | 结构拆解：让学生亲手把六大意象归入「远眺／近观／仰视／俯瞰」空间方位，并标注动静与色彩，把教师讲过的写景艺术转化为可操作的结构认知 |
| linked_objective | 教学目标 3；教学重点（赏析意境特点、梳理景事情志四层结构） |
| teacher_action | 展演结束后分发互动页，要求学生独立完成归类；教师投屏展示典型结果，点出「远近俯仰、高低错落构成的全景图」 |
| student_action | 学生将六个意象拖入四个空间方位，并勾选每个意象的动静属性；完成后提交查看归类和解析 |
| duration | 课堂约 5 分钟 |
| required | true |
| status | planned |
| execution_owner | Agent HTML |
| html_handoff_target | `agents/html-courseware/AGENT.md` |

### 3.2 互动规格

- **html_input**：上阕写景六句原文（万山红遍、层林尽染、漫江碧透、百舸争流、鹰击长空、鱼翔浅底），以及四个空间方位框（远眺／近观／仰视／俯瞰）与动静属性选项。
- **html_interaction**：拖动六个意象卡片到对应空间方位框；每个卡片需选择「静／动」属性；全部放置完成后点击「提交」。
- **html_feedback**：
  - 正确：卡片变绿并锁定，显示该句的赏析要点（如「层林静立为静，山林赤红为色彩之壮」）。
  - 错误：卡片抖动并标红，提示「再看看词人是抬头看还是低头看」，允许重试，不显示正确答案。
  - 重置：提供「重新开始」按钮，清空所有归类和状态。
  - 完成：全部正确后展示完整的「立体全景湘江秋景图」结构图与一句总结。
- **html_runtime**：电脑或平板浏览器，Chrome／Edge 近两年版本；单文件 HTML，离线可用，无需联网、无需安装。
- **html_fallback**：无法运行时，改用纸质「意象归类卡」——教师把六句原文印成小卡片，学生在《研学导游手册》上画出四个方位框并粘贴归类，口头说明依据；教学闭环不变。

### 3.3 预期产出

学生能独立说出六个意象的空间分布与动静属性，并用自己的话解释「远近俯仰、高低错落构成立体全景湘江秋景图」。

### 3.4 核验（verification）

1. 六个意象的方位归属须与原文一致：万山红遍、层林尽染→远眺；漫江碧透、百舸争流→近观；鹰击长空→仰视；鱼翔浅底→俯瞰。
2. 动静属性须与原文一致：层林、漫江为静；百舸、鹰、鱼为动。
3. 完成态总结语须与板书「远近动静 壮阔蓬勃」一致，不得引入新的解读结论。

### 3.5 权利与交接

- rights_note：HTML 为本地生成单文件，不含第三方素材；词作原文引用自教材，仅作教学使用。
- handoff_note：由 Agent HTML 生成可运行文件，交由 Agent B 放入正式课件；课件中该页须保留静态备用内容。

## 四、AI 赋能必要性说明

原设计已在打卡点位二写明 AI 生成意境画面，本轮沿用于是「沿用」而非「新增装饰」，符合 Agent A 阶段 3「先判断原设计是否已存在有效 AI 环节」。

新增 AI-02 的理由：教学重点「赏析意境特点、梳理景事情志四层结构」在原设计中仅靠口头展演达成，学生缺少可操作的自我检验环节；意象空间归类直接对应教学重点，且离线单文件即可运行，属最轻量可落地方案。该项已列为需教师确认项，不采用时不影响教学闭环。

未堆叠第三项 AI 任务；AI-01 为视频、AI-02 为互动，二者分别服务「情境还原」与「结构拆解」，不重复。
