## 四、必须保留的教学要素

**教学重点**：赏析湘江秋景壮阔蓬勃的意境；梳理景、事、情、志四层结构；借景抒情、情景交融、景志同构。

**教学难点**：阐释「问苍茫大地，谁主沉浮」的时代内涵；读懂壮秋意象背后的革命胸襟；理解弃悲扬壮、以景衬志的审美价值。

**关键论断（课件引用时不得改写）**：

- 「独立」并非孤寂落寞，而是青年志士临风而立、俯瞰山河的从容笃定、清醒坚毅
- 「寒秋」不写凄冷，暗合时代清冷动荡的背景
- 「怅」不是失意惆怅，而是面对辽阔山河、飘摇时局的深沉忧思与时代担当
- 传统文人悲秋立足「小我」，青年词人写秋立足「大我」
- 景为心之声、境为志之形

**四维解说框架（课件核心页必须体现）**：

色彩之壮 / 空间之阔 / 动静之活 / 意境之升

**六大意象**：万山、层林、漫江、百舸、鹰、鱼

**板书（须原样呈现）**：

```
沁园春·长沙（橘子洲研学导览图）
毛泽东
【观景台 · 绘秋景】远近动静 壮阔蓬勃 → 山河之美
【问天台 · 抒胸臆】叩问大地 谁主沉浮 → 时代之思
【青春馆 · 忆峥嵘】风华正茂 挥斥方遒 → 少年之志
景壮 · 气豪 · 志远 · 担当
```

**评价**：课堂评优「金牌诗词导游」「优秀研学小组」；分层情境作业三层（背诵默写／150—200 字导游解说词／短评新时代青年何为主沉浮）。
