# 语文 AI 课件·选题与制作计划

> 制定日期：2026-10-21
> 教材数据来源：国家中小学智慧教育平台（basic.smartedu.cn / zxx.edu.cn）教材体系 + 人教社官方电子教材，多源交叉核对
> 原始目录：`_教材目录/小学_统编版_语文.md`、`_教材目录/初中_统编版_语文.md`（高中目录见附录 A）

---

## 一、项目定位

**只做语文**，不再接数学、生物、化学、物理、英语等学科课件（历史项目 `DNA分子的结构_高一生物`、`氧化还原反应_高一化学`、`Bananas七上英语` 等仅作流水线参照，不再新增）。

**交付目标不是"好看的课件"，而是教师真实需要、AI 真正解决了问题的课件。** 判定标准只有一条：

> 这课上，有没有一件事是教师自己做不了、而 AI 能做好的？
> 有 → 做。没有 → 不做，哪怕课文很经典。

## 二、教材体系（已核实，与直觉不同）

### 2.1 语文没有"多版本"，只有一个统编版

这是本次核实最重要的结论，直接影响选题策略：

| 学科 | 版本情况 |
|---|---|
| 数学 | 人教 / 北师大 / 苏教 / 西师 等多版本并行 |
| 英语 | 人教PEP / 外研 / 译林 / 冀教 等多版本并行 |
| **语文** | **全国统一「统编版」（部编版，教育部组织编写、人民教育出版社出版，总主编温儒敏）** |

所以本计划**不按版本分册**，而按 **学段 × 学制 × 审定年份** 三个真实维度分。

### 2.2 真正的"版本差异"在两个地方

**（1）学制**：六三制 vs 五四制
- 平台教材栏目里初中语文统编版实际**两套并行**——六三制（全国绝大多数地区）和五四制（山东、上海等地）。两套**单元编排不同**。
- 本计划目录采用 **六三制**。若面向五四制地区，需重采目录。

**（2）审定年份（最大风险）**
统编教材自 2024 秋起启动修订，**三年分批替换完毕**。新旧目录差异很大，不能沿用旧目录：

| 学段 | 册次 | 当前在用版本 | 换新时间 |
|---|---|---|---|
| 小学 | 一上（2024）、一下/二上（2025）、二下/三上（2025-2026）、三下/四上/五上/六上（2026） | 修订版 | 已启用 |
| 小学 | **四下、五下、六下** | **2019 版** | **2027 春换新** |
| 初中 | 七上（2024 秋）、七下（2025 春）、八上（2025 秋）、八下（2026 春）、九上（2026 秋） | 修订版 | 已启用 |
| 初中 | **九下** | 现行旧版 | **2027 春换新** |
| 高中 | 必修上/下、选择性必修上/中/下 | 2019 统编版 | 暂无修订计划 |

**结论**：
- 四下、五下、六下、九下这 4 册，**2027 春后目录会变**，做课时优先做"修订版已确定不会动的课文"，或注明适用年限。
- 修订版改动很大，例如四上删《走月亮》、新增"世界文化遗产"单元（《长城》《颐和园》《秦兵马俑》）；七下删《老王》《叶圣陶先生二三事》《最苦与最乐》《一棵小桃树》，新增《有为有不为》《青春之光》；九上把明清小说单元与九下史传文言文**整体对调**。

## 三、选题判据：什么样的课才配做 AI 课件

### 3.1 六条"AI 真解决问题"判据（命中任一即可入选）

| 编号 | 判据 | 说明 | AI 手段 |
|---|---|---|---|
| **J1** | **情境/场景还原** | 课文写的时代、自然景象、建筑空间，学生没见过、教师也画不出来 | 生图 / 情境短视频 |
| **J2** | **过程/原理可视化** | 事件经过、工艺原理、科学机制，靠讲说不清 | 动画 / 流程图 |
| **J3** | **抽象结构拆解** | 论证结构、情感脉络、人物关系、意象系统 | 图解动画 / 关系图 |
| **J4** | **文化背景补白** | 古代器物、礼仪、服饰、书画、民俗 | 复原图 / 对比图 |
| **J5** | **时空跨度对比** | 人物前后变化、时代变迁、同一母题跨文本 | 对比动画 / 时间轴 |
| **J6** | **意境具象化** | 古诗词意象、留白之美，语言讲不透 | 意境图 / 音画合成 |

### 3.2 五条排除项（命中即不做）

1. **非课文板块**：识字、汉语拼音、语文园地、习作指导、口语交际、快乐读书吧、综合性学习、名著导读、写作专题。这些不是"课"，也没有 AI 赋能点。
2. **一、二年级全部课文**：以识字、儿歌、短童话为主，篇幅短、理解难度低，教师用实物/表演即可解决，AI 边际价值≈0。
3. **篇幅过短、主旨单一的寓言/童话**（如《乌鸦喝水》《坐井观天》《小猴子下山》）：一节课讲透，无需可视化。
4. **纯知识直给型说明文**（无结构/原理难点）：读一遍就懂，AI 只是配图。
5. **AI 只会"配插图"的课**：即把课文文字搬到 PPT 上再配几张图——**这不是 AI 赋能，是排版**。

### 3.3 分级

| 级别 | 含义 | 判据命中 |
|---|---|---|
| **S** | 首选，AI 价值最高，做出来教师会主动转发 | 命中 ≥2 条，且其中含 J1/J2/J6 |
| **A** | 有价值，按批次做 | 命中 1 条 |
| **B** | 可做可不做，优先级最低 | 仅外围价值 |
| **—** | 不列入计划 | 命中排除项 |

## 四、学段策略：为什么重心在初高中

| 学段 | 教师痛点 | AI 可替代度 | 优先级 |
|---|---|---|---|
| **高中** | 篇目长、文言难、文化深、课时紧、复习压力大 | **最高**（情境还原 + 结构拆解需求最刚） | **P0** |
| **初中** | 文言文 + 长现代文 + 名著整本书，学生读不进去 | 高 | **P0** |
| 小学高段（4-6） | 说明文/景物散文讲不生动；古诗没画面 | 中（说明文、古诗类高） | P1 |
| 小学中段（3） | 开始有像样的散文与古诗 | 中 | P1 |
| 小学低段（1-2） | 识字拼音为主 | 低 | **不做** |

**排产建议**：高中 → 初中 → 小学高段 → 小学中段。理由是高中课件单价最高、教师付费/转发意愿最强，且古诗文密度大，正好是 AI 生图的强项。

## 九、风险与质量红线

| 风险 | 说明 | 应对 |
|---|---|---|
| **教材修订** | 四下/五下/六下/九下 2027 春换新，目录会变 | 这 4 册标注适用年限；优先做确定不动的课文 |
| **学制差异** | 六三制 vs 五四制编排不同 | 选题前确认目标地区学制 |
| **旧目录陷阱** | 网上大量 2016/2017 审定旧目录仍在流通 | 一律以最新审定版为准，核对册次标注 |
| **AI 内容准确性** | 古文场景、历史细节容易出错 | 情境图/视频只做氛围，不在画面里写具体年代史实 |
| **排版红线** | 见 `working/proofread_deck.py` | 越界、文字重叠、字号过小必须清零 |
| **附件上限** | 知识星球单附件 ≤ 50MB | 用 `make_light_pptx.py` 压到 40MB 以内 |
| **发布门禁** | 公众号正式发布需 freepublish 权限；知识星球默认在公众号发布成功后触发 | 遵守 SKILL 门禁，不越权 |
