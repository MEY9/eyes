## 〇、开工前置条件（硬门禁，每课必须先满足）

**依据 `agents/teaching-design-enhancer/AGENT.md`（Agent A）：**

1. **教学设计不得由 AI 自行综合生成。** Agent A 规则 1：默认模式是「基于现有教学设计的轻量改写」，**不是从零创作**。
2. **没有现有来源 = 必须暂停。** Agent A 第 7 节：「没有现有设计却要求按'轻量改写'交付」属于必须暂停项。
3. **Agent B 不重新编写教学设计**（`agents/education-ppt-pipeline/AGENT.md` 第 19 行）。

**因此每课开工前，用户必须先提供以下任一来源，存入 `source_materials/`：**

| 可接受的来源 | 处理方式 |
|---|---|
| 现有教学设计（DOCX / PDF / 图片 / 粘贴文本） | 原文只读归档，改写写入新文件 |
| 教参、教研资料原文 | 同上 |
| 微信公众号文章公开链接 | 走 `$read-wechat-articles` 读取，完整 JSON 存 `source_materials/wechat_article.json` |

**来源到位后 Agent A 依次产出**：`source_audit.md` → `lesson_packet.json`（含 objectives / key_points / difficult_points / teaching_steps / ai_tasks）→ `teaching_design.md` → `teaching_design.docx` → `change_log.md` → `ai_assets_manifest.md` → `handoff.md` → `rights_manifest.md` → `pipeline_state.json`。

**课时以来源为准**：来源写明几课时就做几课时，不得擅自扩课时；页数由课时和教学动作决定，不预设固定值。

> ⚠️ 教训记录（2026-10-21）：立项《沁园春·长沙》时曾用 WebSearch 抓教研资料自行综合出教学目标与教学步骤，属越界，已全部撤回。检索教研资料只能用于**交叉核验**来源中的事实，**不能当作教学设计的来源本身**。

## 七、通用约束（每课都必须满足）

1. **AI 赋能真实**：必须有可核验产物 + 课堂作用 + 备用方案；只有提示词或静态截图不算完成。
2. **AI 视频成本**：默认 8–15 秒，不为了填满环节拉长；本课无强视频需求时改用 HTML 或素材图。
3. **HTML 单文件可离线**：含预览、静态备用、嵌入说明、运行检查；课件内保留静态备用页。
4. **对象级可编辑**：底图 / 文字 / 形状 / 素材 / 线条 / 表格 / 图标 / 遮罩全部拆为可编辑对象，禁止整页图片冒充文字。
5. **字体**：宋体为主、黑体为辅，禁用书法体 / 艺术字 / 描边字；正文投影不小于 24px（1920×1080 计）。
6. **排版**：单页一个主要教学动作，文字覆盖率不超过 55%。
7. **合规**：不出现品牌 logo、水印、参考帖原文文字；AI 生成素材登记 `rights_manifest.md`。
8. **发布门禁**：公众号只建草稿，正式发布需明确指令；知识星球默认在公众号正式发布成功后触发。
