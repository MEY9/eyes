# GitHub 项目收藏库

## 用途

用于长期保存与教育课件、教育可视化、PPT 产品、HTML 课件、交互演示、2.5D/3D 视觉资产和 AI 辅助创作相关的优秀 GitHub 项目。

保存项目时，不只记录链接，还要说明项目能解决什么问题，以及它与本项目的关系，避免以后只收藏链接却忘记用途。

## 审核规则

任何项目进入正式收藏库前，都必须先经过项目负责人审核。

项目状态使用以下值：

- `待审核`：已经发现，但尚未确认是否值得长期保存。
- `已收录`：审核通过，进入正式收藏库。
- `暂不收录`：项目有一定价值，但当前与本项目关系较弱。
- `不收录`：质量、维护情况、授权或适用性不符合要求。

## 记录字段

每个项目至少记录：

- 项目名称
- GitHub 链接
- 项目状态
- 主要功能
- 对本项目的用途
- 适用产品类型
- 技术栈或关键技术
- 是否值得深入研究
- 备注

- 技术栈：Prompt-as-Code、结构化提示词、Agent Skill；仓库同时包含 Web 图库与相关前端/服务端代码，具体技术栈待确认。
- 值得深入研究：是
- 备注：公开仓库，页面标注 MIT 许可证；项目包含第三方公开提示词与示例图片的整理，使用时需分别核查素材来源、授权与商用限制。

- GitHub：<https://github.com/andyhuo520/html-ppt-designer>
- 状态：已收录

- 技术栈：Python、JSON、HTML/CSS、JavaScript、Playwright、FFmpeg、Edge TTS/OpenAI TTS/国产 TTS，以及 Unsplash 和 ZENMUX 配图接口。
- 值得深入研究：是
- 备注：公开仓库，页面标注 MIT 许可证。当前源码快照中部分风格模板文件缺失，`E1` 等风格可能回退到默认模板；AI 配图结果与 HTML 图片映射之间也需要进一步核验。项目主要输出 HTML/MP4，不直接生成原生可编辑 PPTX。

### codex-ppt-skill

- GitHub：<https://github.com/ningzimu/codex-ppt-skill>
- 状态：已收录
- 主要功能：面向 Codex 及其他支持 `SKILL.md` 的 Agent，将文章、报告、论文、课程笔记或大纲转换为统一视觉的 16:9 图片式 PPT/PPTX；支持先确认大纲、视觉风格、图片后端和样例页，再批量生成整页幻灯片图片，最后组装为 `.pptx`；同时支持参考 PPT/PDF/截图进行风格匹配、指定原始素材、演讲者备注和生成状态记录。
- 对本项目的用途：为教材 PDF 到教育 PPT 的生产流程提供一套更严格的图片式演示工作流，重点参考其阶段性确认、样例验收、逐页任务状态、图片来源记录和最终质量检查；可与当前 HTML 课件和可编辑 PPT 分支互补，用于快速制作视觉统一的课程讲解稿。
- 适用产品类型：教育 PPT / 课程演示 / 图片式 PPTX / 教学课件 / 视觉提案
- 技术栈：Codex Skill、Python、OpenAI Images API 或内置图像生成后端、PPTX 组装脚本、Markdown/JSON 工作流状态文件。
- 值得深入研究：是
- 备注：图片式页面将文字、图表和插画整体生成在单张幻灯片图像中，视觉统一性强，但页面内元素不等同于原生可编辑文本框；使用时需按原仓库许可证和第三方素材授权要求执行。

- 值得深入研究：是
- 备注：项目已安装为 Codex skill，并同步到本仓库的 `skills/image-to-editable-ppt/`；它不是从零创作 PPT 的工具，复杂视觉通常仍会保留为图片层，最终效果依赖 OCR、字体和本机 PPTX 回渲染环境；公开仓库 README 标注 MIT 许可证。

## 使用约定

当收到“帮我存储 GitHub 链接”指令时：

1. 先确认项目是否与本项目有关。
2. 记录项目的功能、用途和与本项目的关系。
3. 新项目默认标记为“待审核”，不得自动视为已收录。
4. 只有获得明确审核通过后，才将状态改为“已收录”。
5. 修改完成后，再由项目负责人决定是否提交并上传远程仓库。
