# eyes 项目长期约定

## 项目定位

教育课件生产系统（`E:/codex/jiaosdhi/eyes`）。**自 2026-10-21 起，本项目只做语文课件**，不再接生物/化学/物理/数学/英语课件。
选题依据：`project/PPT课件/语文课件选题与制作计划.md`（S 132 / A 108，共 240 课，9 批排期）。

## 铁律：教学设计不得由 AI 自行创作

**来源**：`agents/teaching-design-enhancer/AGENT.md`（Agent A）规则 1、第 7 节；`agents/education-ppt-pipeline/AGENT.md`（Agent B）第 19 行。

1. Agent A 默认模式是「**基于现有教学设计的轻量改写**」，**不是从零创作**。
2. **「没有现有设计却要求按轻量改写交付」属于必须暂停项。**
3. **Agent B 不重新编写教学设计**，只承接交接包制作课件。
4. **WebSearch / 教研资料只能用于交叉核验来源中的事实，不能当作教学设计的来源本身。**

每课开工前必须先有来源存入 `source_materials/`：用户提供的现有教学设计（DOCX / PDF / 图片 / 粘贴文本）、教参或教研资料原文、或公众号公开链接（走 `$read-wechat-articles`）。
**用户授权「你自己找」时，可自行检索网络上的现有教学设计原文**——找到的仍必须是真实存在的完整原文并原样归档，**不得自行编写或把多篇综合成一份新设计**。

### 自行检索来源的可用方法（2026-10-21 实测）

- ⚠️ Bash 的 curl / Python urllib 走 sandbox 代理会 502；**改用 PowerShell 工具的 `Invoke-WebRequest`（.NET 栈）可正常出网**。WebSearch 工具可用。
- ✅ 可用源站：`zy.21cnjy.com/<id>`、`mip.21cnjy.com/P/<id>.html`（二一教育，页面直接渲染大量正文）、`yeyulingfeng.com`（夜雨聆风，正文最完整、以 `-END-` 收束）。
- ❌ 不可用：book118 / zhijidoc / renrendoc / 道客巴巴 / 百度文库 —— 多为「几百到两千字预览 + 付费下载」，正文不可读。
- 完整性判据：**结构闭合**（目标 + 重难点 + 多环节过程 + 作业/板书/反思）+ **明示课时**；出现「展开更多」折叠或句中截断即判不合格。
- 多来源处理：**主来源唯一**，其余仅作事实核验与课时佐证，**不并入改写**（多源合成等于变相创作）。
- 课时冲突时以主来源为准，不得擅自扩课时。

来源到位后 Agent A 才产出：`source_audit.md` → `lesson_packet.json` → `teaching_design.md` → `teaching_design.docx` → `change_log.md` → `ai_assets_manifest.md` → `handoff.md` → `rights_manifest.md` → `pipeline_state.json`。

**课时以来源为准**（来源写几课时就做几课时）；**页数由课时和教学动作决定**，不预设固定值，不得沿用上一套课件的页数。

> 教训（2026-10-21）：立项《沁园春·长沙》时用 WebSearch 抓教研资料自行综合出教学目标/重难点/教学步骤并生成了 teaching_design.docx，被用户当场指出越界，已全部撤回（删 docx、清空 lesson_packet 教学设计字段、deck_spec 的课时/页数/目标置 null）。

## 语文教材体系

- **语文全国统一统编版（部编版）**，不像数学/英语有多版本并行，因此选题**不按版本分册**。
- 真实存在的两个维度：**学制**（六三制 / 五四制，编排不同，本项目取六三制）、**审定年份**。
- **教材修订是最大坑**：2024 秋起分批修订三年换完；四下/五下/六下/九下要到 **2027 春**才换新，现仍为 2019 版。这 4 册做课件须标注适用年限。
- 教材目录数据：`project/PPT课件/_教材目录/小学_统编版_语文.md`（12 册）、`初中_统编版_语文.md`（6 册）。

## 课件流水线

完整工序见 `project/PPT课件/_流水线/第1批_高中必修S级_立项清单.md` 第五节（阶段 0–15）。
可复用脚本基线在 `project/PPT课件/赤壁赋_高一语文_完整流程/working/`（15 个 .py）。
通用工具放 `project/PPT课件/_流水线/`：
- **`md_to_docx.py`（推荐）** —— Markdown → 正式 DOCX 渲染器：宋体五号纯黑、普通 Word 表格，`---` 转空段落，反引号 / 加粗标记 / 列表符全部清洗，板书用缩进块。**单一数据源**（直接吃 `teaching_design.md`），后续 14 课复用。
- `build_teaching_design_docx.py` —— 从 `lesson_packet.json` 生成 DOCX。**已不推荐**：会导致 md 与 docx 两份数据不一致。
- 两者**只做排版，不产生教学内容**；内容必须由 Agent A 填好。

关键门禁：
- **风格确认是硬门禁**：3 种候选 × 每种 3 张代表页，打包 `风格1/2/3.pdf`，用户确认前不得批量生成。
- **同质化防护**：连续课件不得沿用同一视觉风格家族，同一风格家族不得三连用。
- **AI 赋能门禁**：必须有真实产物 + 课堂作用 + 核验 + 静态备用，只有提示词或截图不算完成。
- **发布门禁**：公众号只建草稿，正式发布需明确指令 + freepublish 权限；知识星球默认在公众号正式发布成功后触发。
- AI 视频只用即梦 API（seedance-2.0-mini/fast-vip），每套课件最多生成 2 次；文生图优先 `.env` 的 OpenAI 兼容接口。
