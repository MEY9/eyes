# wechat-ios-showcase@1.0

## 定位

`wechat-ios-showcase@1.0` 是微信公众号教育案例的精品展示主题。主题 ID 为兼容既有产物保留，当前视觉规范已调整为壹伴“简单教育”方向的编辑部图文结构，不再使用 iOS/App UI 组件语言。

该主题是公众号课件文章的默认精品主题。构建命令可直接省略 `--theme`；以下写出主题参数便于交接时明确版本：

```powershell
python skills/ppt-social-publishing/scripts/build_wechat_article.py `
  --theme wechat-ios-showcase@1.0 `
  --article <article.md> `
  --planet "一堂微课" `
  --planet-qr <qr-card.jpg> `
  --out <article_ios_showcase.html>
```

## 视觉原则

- 内容优先：正文保持 16px、约 1.9 倍行高，标题不超过 24px，适合教师在手机端连续阅读。
- 教育型色彩：正文使用深蓝灰，章节数字使用暖黄色，蓝色仅用于少量学科信息，青绿色仅用于互动内容。
- 区块图文：按完整章节使用暖白、灰蓝、浅绿纸张底色，区块之间留出白色间隔；同一章节内容放在一起，不为每张图片重复套卡。
- 长画廊按教学阶段分组：每组使用独立浅色底、页码范围和阶段标题，组间保留明显留白，避免全部幻灯片连续铺在同一白底上。
- 无框分区：不使用章节横线、标题竖线、网格分隔线、图片描边或数据面板；主要依靠字号、间距和图文比例建立层级。
- 大图优先：GIF、HTML 互动截图与幻灯片按接近正文全宽展示，图片下方只保留一行克制图注。
- 不使用渐变、玻璃拟态、模拟手机外壳、深色媒体框、胶囊标签或明显投影。
- 素材风格统一；GIF 只承担“过程变化”的演示，不作为装饰。

## 固定结构

1. 刊头：教材信息、主标题、副标题、课件封面与纯文字主题信息。
2. 导语：提出教师真实痛点与文章价值。
3. 章节：暖黄色两位数字居中，中文标题居中，不添加横向分隔线或背景卡。
4. 媒体：课件实景或动态演示直接展示，图片下方使用简短灰色图注。
5. 内容摘要：把页数、课时、视频与互动数量写成一行自然信息，不使用指标宫格。
6. 资料包：四项内容纵向排列，以序号、文件类型、名称和元信息分层展示，不使用表格网格。
7. 转化区：原生小程序卡片插入锚点在前，用户提供的二维码卡片在后；不添加品牌落款。

## 知识星球小程序

HTML 不伪装小程序按钮。主题在转化区写入唯一注释锚点：

```html
<!-- WECHAT_MINIPROGRAM_INSERT: 在此插入知识星球原生小程序卡片 -->
```

公众号 API 创建草稿后，由运营者在微信后台打开草稿，在注释锚点位置插入知识星球原生小程序卡片。正文不显示面向运营者的操作提示或伪按钮；二维码卡片保留在小程序卡片下方作为备用入口。

## 兼容边界

- 所有样式必须内联。
- 禁止 `<style>`、`class`、`id`、CSS 变量、脚本、表单、iframe、SVG、Canvas、音视频节点。
- 不使用 Grid、复杂 Flex、固定定位、粘性定位、媒体查询和 `gap`。
- 横向指标仅使用 `<table>`。
- 正文图片必须包含 `max-width:100%;height:auto;display:block;`。
- 正文图片发布前必须上传到微信并替换为 `media/uploadimg` 返回地址。
- 发布前在 iPhone 浅色与深色模式各预览一次，并核对小程序卡片、二维码识别、GIF 首帧与全文顺序。

## 验收证据

- 输出 HTML、预览 HTML、素材清单和主题元数据。
- 主题元数据中的 `theme_id` 必须等于 `wechat-ios-showcase@1.0`。
- `WECHAT_MINIPROGRAM_INSERT` 锚点只能出现一次。
- 所有本地素材存在，图片顺序与源文一致。
- 禁用标签、禁用 CSS 与敏感占位内容扫描为零。
