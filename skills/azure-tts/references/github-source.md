# Azure Speech SDK 来源

本项目采用微软官方示例作为实现参考：

- 仓库：https://github.com/Azure-Samples/cognitive-services-speech-sdk
- Python 文本转语音快速开始：https://github.com/Azure-Samples/cognitive-services-speech-sdk/tree/master/quickstart/python/text-to-speech
- Python 文本转语音示例文件：https://github.com/Azure-Samples/cognitive-services-speech-sdk/blob/master/quickstart/python/text-to-speech/quickstart.py

采用原因：官方仓库提供 Python、macOS 和 Speech SDK 的直接示例，适合本项目的本地 `.env` 配置和课件音频文件生成。这里只借鉴 SDK 调用方式，不把仓库代码原样复制为课件内容。
