# PPTX 动画后处理规范

本文件是 image-to-editable-ppt 的动画实现层规范。Agent B 负责依据教学逻辑提供动画组、顺序和效果选择；本规范负责将已完成对象级重建的 PPTX 加入原生 PowerPoint 动画，并验证结果。

## 适用范围

只对已经通过 `editppt run finalize` 的可编辑 PPTX 做后处理。动画后处理不是视觉稿生成，也不是把整页图片做成动画。原有文字、形状、线条、图片、表格和图示必须保持对象级可编辑。

## 动画计划

动画计划至少包含以下信息：

- `slide`：页码；
- `groups`：按课堂教学动作排列的动画组；
- 每组的 `purpose`：本次点击要讲解、揭示或引导的内容；
- `shape_ids` 或稳定对象名称：本组对象；
- `effect`：`fade`、`wipe`、`circle_in`、`appear` 等受支持效果；
- `motion`：擦除方向，必须与内容流向一致；
- `trigger`：教师点击触发，组内对象可使用 `withEffect`；
- `duration_ms`：通常 400～800 毫秒；
- `excluded_static_objects`：明确保持静止的背景、底图和装饰对象；
- `reason`：效果与教学逻辑的对应理由。

## 实现规则

1. 先读取动画计划，不能按对象数量自动逐个添加动画。
2. 一个教学动作中的标题、说明、证据、对应插图、箭头和曲线应合并到一个点击组或紧邻的组内。
3. 背景、纸张纹理、固定边框、整页装饰和不承担讲解顺序的素材默认静止。
4. `fade` 用于平稳进入，`wipe` 用于方向、流程和情感曲线，`circle_in` 用于关键证据或聚焦，`appear` 用于答案或关键词即时揭示。
5. 不默认使用旋转、弹跳、随机飞入、复杂路径和循环动画；确需使用时必须在动画计划中说明教学目的。
6. 每页动画组数量由课堂逻辑决定。出现“每个元素一个点击”的结果时，必须返修分组。
7. 动画后处理只能写入 PPTX 的 timing、transition 和相关动画 XML，不得改变重建 manifest 的对象来源和坐标。

## 验收

后处理必须同时保留以下记录：

- 动画计划或 `animation_manifest.json`；
- 每页组数、效果分布、触发方式和对象 ID；
- PPTX 包结构校验结果；
- 所有动画目标对象存在且 `cTn` ID 不重复；
- 页数、顺序、媒体关系和对象数量未被意外改变；
- 可用 PowerPoint 时完成实际点击播放检查；没有 PowerPoint 时，完成结构校验、`unzip -t` 和 LibreOffice 页面渲染，并明确未完成 PowerPoint 播放验证。

动画后处理失败、对象目标缺失、背景被批量动画化、动画与教学目的不匹配或播放效果单调时，不得将该版本标记为完成。
