# 教育 PPT 产品 Skill

当用户要把教材、课程资料或 PDF 制作成教育 PPT 产品时使用。默认全中文，并按阶段推进，不一次性批量制作全部页面。

## 核心目标

把教材内容转成：

```text
教学目标 → 页面故事板 → 视觉系统 → 可编辑 PPTX → AI 媒体 → 可选 HTML 互动 → 商品包
```

## 默认流程

1. 分析教材：提取目录、知识点、学习目标、来源页码和不确定内容。
2. 定义产品：明确学习对象、场景、页数、时长、交付格式、AI 媒体和 HTML 范围。
3. 建故事板：每页绑定教学目标、页面目的、视觉主体、用户动作和反馈。
4. 建视觉系统：确定色彩、字体、构图、留白、镜头、风格、AI 提示词和资产命名。
5. 生产内容：优先完成一个代表性章节，再批量生成；PPT 文字和形状保持可编辑。
6. QA 和包装：检查内容、版式、投影、视频、链接、授权、版本和使用说明。
7. 记录迭代：保存工作量、返工原因、复用组件和下一版本决策。

## 必须遵守

- 不凭常识补全教材中的关键知识；保留来源页码。
- AI 图片和视频先记录来源、生成方式、参考图和授权判断。
- AI 视频默认是固定媒体，不承诺任意修改。
- PPT 必须保留可编辑文字、形状和合理的媒体层。
- HTML 互动必须明确独立运行、超链接跳转或其他运行方式。
- 医学、法律和安全内容需要专业审核记录。
- 未确认目标设备和产品边界前，不批量生产高成本媒体。
