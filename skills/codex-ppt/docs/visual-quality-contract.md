# Codex PPT 视觉质量契约

本文件只约束 codex-ppt 的视觉稿阶段，不改变 Agent A 的教学设计、image-to-editable-ppt 的对象重建或动画视频流程。

## 1. 页面视觉契约

每页生成前必须从 `outline.md` 或 `deck_spec.json` 得到以下字段：

```json
{
  "teaching_function": "导入|讲授|提问|活动|练习|反馈|总结|作业",
  "attention_priority": ["第一视觉重点", "第二视觉重点"],
  "content_density": "low|medium|high",
  "text_budget": {
    "title": "短标题",
    "key_points_max": 4,
    "long_paragraphs": false
  },
  "visual_metaphor": "与本页教学内容直接相关的视觉表达",
  "layout_rationale": "为什么使用这个构图，以及观众先看哪里",
  "must_be_visible": ["必须出现的文字、图示、素材或操作入口"],
  "avoid": ["不得出现的装饰、重复布局或错误信息"]
}
```

页面不能只有“好看、专业、清爽”等泛化描述。必须说明教学动作、视线顺序、信息密度和视觉表达之间的关系。

文字过多时优先拆页，不把整段教学设计压缩进一张图片。标题和关键点必须短、准、可投影阅读；图片内文字必须与大纲完全一致。

## 2. 样张组门禁

正式课堂课件默认生成三类代表性样张：

1. 封面或情境导入页：验证主题气质、标题层级和第一印象；
2. 普通讲授页：验证文字密度、知识层级和投影可读性；
3. 活动、练习或反馈页：验证课堂操作、问题突出和视觉节奏。

三张样张必须使用同一后端、同一生成模式和同一视觉系统，但不能使用同一个固定构图。用户确认的是一组视觉规则，而不是一张页面模板。

只有以下情况允许使用一张样张：用户明确要求跳过样张组，或课件确实只有一种页面角色。此例外必须记录在 `deck_spec.json` 的 `sample_policy.exception` 中。

样张组批准前，不生成完整课件。任意一张样张出现严重文字、布局、教学层级或风格问题，都不能进入全量生成。

## 3. 页面视觉评分

每页生成后建立 `qa/slide_XX_review.json`，按 0～2 分记录：

- `teaching_hierarchy`：教学重点是否一眼可见；
- `text_fidelity`：中文是否准确、完整、无乱码和截断；
- `layout_usability`：构图是否服务讲解，留白、对齐和层级是否合理；
- `visual_logic`：插画、图示、箭头和装饰是否解释内容，而非堆装饰；
- `projection_readability`：远距离投影时标题、正文、标签是否可读；
- `font_legibility`：不使用艺术字、书法体、毛笔体、装饰体、手写体或变形字；
- `style_consistency`：色彩、字体气质、材质、图标和插画语言是否统一；
- `layout_variation`：是否避免与相邻页重复，且没有为了变化破坏结构；
- `asset_integrity`：必须使用的素材、数据、标签和关系是否保真。

总分低于 16/18，或 `text_fidelity`、`teaching_hierarchy`、`font_legibility`、`asset_integrity` 任一为 0，必须返工。页面评分不能替代人工查看，只是让返工理由可追踪。

## 4. 全套节奏审核

完整生成后必须生成 `qa/deck_contact_sheet.png` 和 `qa/deck_review.md`，从缩略图整体检查：

- 连续页面是否重复同一种三卡片、左右分栏或人物站位；
- 封面、讲授、活动、练习、总结是否有清晰段落差异；
- 页面密度是否忽高忽低；
- 视觉重点是否随着教学过程推进；
- 是否存在重复插画、重复装饰或无关元素；
- 是否有某一页明显偏离整体风格；
- 是否出现全套颜色过艳、过暗或投影不清的情况。

整套节奏不通过时，优先返工构图和页面角色，不通过统一滤镜或批量叠加装饰解决。

## 5. 返工顺序

按问题范围选择最小返工：

1. 内容或提示词错误：修正该页 `deck_spec` / prompt 后重新生成；
2. 局部文字或局部视觉问题：使用已确认后端的编辑能力修复；
3. 构图、密度或教学层级问题：重新生成该页；
4. 多页出现同一类问题：修正全局视觉方向或页面类型规则，再批量返工受影响页面；
5. 同一页连续两次不通过：保留失败记录并暂停，说明问题和证据，不用本地绘图或整页截图替代。

每次返工记录原因、修改字段、生成方式、旧图路径、新图路径和复核结果。通过的页面不因单页返工而重新生成。

## 6. 生成禁止项

- 不用一个封面样张套用所有页面；
- 不把同一插画、同一人物姿势或同一布局复制到整套课件；
- 不用“更精美、更高级、更丰富”等词代替具体构图指令；
- 不为了填满画面增加无教学意义的装饰；
- 不把文字保真问题留给 image-to-editable-ppt 阶段补救；
- 不使用艺术字、书法体、毛笔体、装饰体、手写体或变形字；
- 不用本地 Pillow、HTML、SVG、PPTX截图或人工叠字生成最终幻灯片图片。
