# Style Lock And Visual Review

本文件把主风格从“描述性偏好”变成可执行的课件生产约束。它参考了 visual-style-ppt-skill 的 Style Lock、缩略图优先、样张审批和定向返工机制，但保留本项目的图像视觉稿 → image-to-editable-ppt 可编辑重建路线。

## 1. Style Lock 的作用

一套课件只允许有一个主风格身份。页面可以根据教学功能改变构图、信息密度和视觉重点，但不能每页更换画风、笔触、色彩逻辑或字体气质。

Style Lock 不是固定页面模板，而是跨页面复用的视觉规则。它必须在正式批量生图前形成，并在样张通过后锁定。

## 2. Style Lock 必填字段

在 `deck_spec.json` 中记录 `style_lock`，至少包括：

```json
{
  "name": "本次课件主风格名称",
  "visual_dna": {
    "mood": "整体情绪和时代媒介感",
    "palette": "主色、辅助色、强调色、中性色及使用比例",
    "line_and_texture": "线稿、纸张、颗粒、阴影和边缘处理",
    "illustration_language": "人物、场景、道具和图示的共同画法",
    "composition_rhythm": "留白、区块、视线和页面节奏"
  },
  "typography": {
    "language": "Chinese",
    "font_mood": "普通、清晰、适合投影阅读",
    "hierarchy": "标题、正文、标签的相对层级",
    "text_density_limit": "单页文字密度上限",
    "forbidden": ["艺术字", "书法体", "毛笔体", "装饰体", "手写体", "变形字"]
  },
  "layout_rules": {
    "safe_margins": "安全边距",
    "grid": "网格和对齐规则",
    "cover_rule": "封面与内页的差异",
    "page_role_variation": "导入、讲授、活动、练习、总结等页面如何变化"
  },
  "decoration_and_assets": {
    "reusable_elements": "边框、图标、纹理、人物和道具",
    "allowed_decoration": "允许的装饰",
    "negative_constraints": "禁止的装饰、标识和时代错置"
  },
  "status": "draft|locked"
}
```

`style_brief` 负责较完整的设计说明，`style_lock` 负责后续生成必须遵守的最小约束。样张通过后将 `status` 改为 `locked`，并把批准的样张路径写入 `approved_style_references`。

## 3. 风格提炼与选择

1. 如果用户已经提供风格图、教材插画或明确风格，直接提炼其可复用规则，不强行提供无关选项。
2. 如果没有明确风格，提供 2—3 个具体候选。候选必须写清色彩、版式、字体方向、插画/素材处理、装饰和信息密度，不能只写“高级”“清新”等空泛形容词。
3. 用户选择后只保留一个主风格来源和一个 Style Lock。多个项目可以组合借鉴，但组合后的规则必须收敛成一个新风格，不得让不同来源在页面之间轮换。
4. GitHub 项目只作为视觉语言、素材组织或生成方法的参考。记录来源和借鉴点，但不把项目原样复制到课件，也不在此流程中增加许可证审查。

## 4. 缩略图优先的两段式生产

对于多页正式课堂课件，先做“缩略图板”再批量生成大图：

1. 完成教学设计交接、课件大纲、Style Lock 和图像后端确认。
2. 生成同一画幅比例的缩略图板，展示整套页面的页面角色、视觉节奏、留白、信息密度和构图变化。缩略图板是规划与审查材料，不是最终课件页。
3. 检查是否出现连续同版式、封面过重、讲授页过密、活动页缺少操作焦点、总结页没有收束等问题。
4. 再生成封面/导入、普通讲授、活动/练习/反馈三张代表性样张，三张都必须服从同一个 Style Lock。
5. 样张通过后，按已批准的风格参考和页面角色生成独立的全尺寸 `origin_image/slide_XX.png`。
6. 缩略图板不能被当作输入素材传给 `image-to-editable-ppt`，也不能代替最终页面图。

如果用户明确要求跳过缩略图板，可以跳过该规划产物，但仍必须保留 Style Lock、代表性样张和整套缩略图/接触表 QA。

## 5. 教学课件的风格约束

- 主风格稳定，页面构图服务教学任务；不要把整套课件做成海报集。
- 内容结构以 Agent A 的教学设计和已确认的大纲为准，不因为风格而删掉教学目标、活动、练习、反馈、总结或作业。
- 课堂文字必须是普通、清晰、适合投影的中文；禁止艺术字、书法体、毛笔体、装饰体、手写体和变形字。
- 页面应允许后续 `image-to-editable-ppt` 拆出文字、背景、图片、形状、线条、图标、遮罩等元素；不要把所有信息压成不可分析的装饰纹理。

## 6. 定向返工与版本记录

发现问题时只修改被指出的页面和必要的相关页面，保留已通过页面、Style Lock 和已确认的生成后端。每次返工记录：

- 版本号和时间；
- 页码；
- 问题类型：内容、文字、布局、风格漂移、素材或可拆解性；
- 原因与修改目标；
- 新旧输出路径；
- QA 结论。

如果问题来自主风格本身，先解锁并修改 `style_lock`，重新生成受影响的缩略图和代表性样张，再继续批量生产。不要在单页提示词里偷偷改变全局风格。
