# 教育 PPT 产品线

## 定位

面向教师、培训机构和教育内容团队，提供可编辑、可演示、带 AI 媒体和可选 HTML 互动的主题教育课件包。

## 第一阶段边界

只做 PPT 产品，不同时开发希沃、万彩和 HTML 产品线。HTML 只作为 PPT 的可选互动增强模块出现。

## 产品组成

```text
教学内容
视觉系统
PPTX 源文件
AI 图片/视频
教师备注
练习和答案
HTML 互动入口（可选）
素材来源与授权说明
```

## 当前推荐 SKU

```text
基础版：PPTX + 图片 + 教师备注
增强版：基础版 + AI 视频 + 字幕
互动版：增强版 + HTML 互动页面
商业授权版：互动版 + 源文件 + 商业使用授权
```

## 第一款产品的通过标准

- 有一个明确学习对象和教学主题；
- 至少完成一个代表章节；
- 3～5 页页面风格统一；
- 至少一个 AI 媒体资产；
- 所有文字保持可编辑；
- 内容有来源记录；
- 能打包成可预览、可说明、可售卖的产品。
