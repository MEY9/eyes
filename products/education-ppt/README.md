# 教育 PPT 产品线

## 定位

面向教师、培训机构和教育内容团队，提供可编辑、可演示、带 AI 媒体和可选 HTML 互动的主题教育课件包。

## 产品边界

主产品是完整课堂 PPT，不同时开发希沃、万彩等独立产品线。HTML 只在教学目标需要且 Agent A 已交接 HTML 任务时，作为 PPT 的可选互动增强模块出现。

## 产品组成

```text
教学内容
视觉系统
PPTX 源文件
AI 图片/视频
教师备注
练习和答案
HTML 互动入口（可选）
素材来源与授权说明
```

## 交付组合

基础交付包含教学设计、完整课堂 PPTX、教师备注、必要资源和 QA 证据。AI 视频、HTML、课件配音、动画视频与发布包装按教学目标和用户需求择一或组合；不得把未核验的素材写成“商业授权”，资源来源与许可状态以项目 `rights_manifest.md` 为准。

## 项目通过标准

- 有一个明确学习对象和教学主题；
- 按来源课时完成整套课堂课件，不设固定页数；
- 全部页面遵守已确认的 `style_id@version` 与 Style Lock；
- 至少一个 AI 赋能任务形成真实产物、课堂作用、核验和备用方案；
- 所有文字保持可编辑；
- 内容有来源记录；
- 能打包成可预览、可说明、可追踪、可验收的项目交付物。
